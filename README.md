This video demonstrates the working ASTRA-SENSE system for AI-based human activity recognition, object detection, object tracking, pose estimation, and human-object interaction analysis.

The demonstration showcases the system's real-time computer-vision pipeline, including astronaut/person detection, object detection, tracking, activity analysis, interaction monitoring, and live system status visualization.

ASTRA-SENSE is designed as a foundation for future on-board BAS experiment monitoring, where AI can assist in monitoring astronaut activities, experimental objects, and protocol execution in space environments.
