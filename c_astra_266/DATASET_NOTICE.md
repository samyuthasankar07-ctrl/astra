# C-ASTRA 266-class synthetic dataset

This dataset contains 266 classes, with 12 training, 3 validation, and 2 test
procedural images per class (4522 images total). Images and YOLO bounding boxes
are generated automatically for pipeline development.

These are synthetic procedural illustrations, not real ISS/BAS photographs.
Metrics obtained on this dataset must not be interpreted as real-world accuracy.
For deployment, add real camera images and real annotations and fine-tune/validate
on a held-out real-world set.
